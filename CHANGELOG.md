# Changelog — The Medalist

All notable changes made to The Medalist website are documented in this file.

## Version 0.1 — Initial Development

* Created the initial project structure.
* Developed the homepage.
* Added initial website navigation and CSS styling.

## Version 0.2 — Website Pages

* Added the Sports page.
* Added the Analysis page.
* Added the Features page.
* Expanded the website's content and navigation.

## Version 0.3 — Additional Pages

* Added the Enquiry page.
* Added the Contact page.
* Included multiple office locations.

## Version 1.0 — Part 1 Completion

* Completed the initial website foundation.
* Established the main page structure and navigation.
* Organised website assets and content.
* Tested the main website pages.

## Version 2.0 — Part 2: Styling and Responsiveness

### CSS and Layout

* Improved the CSS reset and box-sizing rules.
* Refined typography and spacing.
* Continued using CSS Grid and Flexbox for page layouts.
* Added navigation focus and active states.

### Responsive Design

* Added tablet and mobile breakpoints.
* Improved layouts across different screen sizes.
* Adjusted typography and content grids for responsiveness.

### Responsive Images

* Implemented responsive image techniques using `srcset`, `sizes` and the `<picture>` element.
* Prepared different image resolutions for supported images.
* Tested responsive image selection using browser developer tools.

### Website Consistency

* Updated the About page to match the website's branding.
* Standardised navigation across pages.
* Corrected project documentation and image directory details.

## Version 3.0 — Part 3: Interactivity and SEO

### JavaScript Features

* Integrated GLightbox for homepage image viewing.
* Added search and category filtering to the Sports page.
* Implemented interactive filtering tabs on the Analysis page.
* Added an FAQ accordion to the About page.
* Created dynamically generated latest-story cards on the homepage.

### Enquiry Functionality

* Embedded a Google Form on the Enquiry page to allow visitors to submit enquiries.

### Search Engine Optimisation

* Added page-specific titles and meta descriptions across the website.
* Updated metadata to better reflect the content of each page.
* Added author, robots and keyword metadata.

### Testing

* Tested the implemented interactive features.
* Checked navigation and page functionality.
* Reviewed SEO metadata across all seven pages.
* Checked that the website's existing responsive layouts remained functional.

### Documentation

* Updated the README to document Part 3.
* Extended the project changelog to reflect the latest development work.
